# キメメシ（仮）

なにも考えなくていい。**4回タップで、今日の一軒が決まる。**

デート・友達との飲み・幹事・ひとり飯 — その日の気分と価格帯・雰囲気・用途を4択で選ぶだけで、お店を1軒言い切りで提案するWebアプリのプロトタイプ。

## 使い方

- `index.html` をブラウザで開くだけで動きます（デモデータ内蔵・インストール不要）
- ホーム画面下のバッジをタップして[ホットペッパーAPIキー](https://webservice.recruit.co.jp/)（無料）を設定すると、現在地周辺の実在店舗の検索に切り替わります

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（単一ファイル・依存なし） |
| `DESIGN.md` | 設計書：質問ツリー、ホットペッパーAPI対応表、決定エンジン仕様 |

## 検索が失敗するとき（プロキシ設置・推奨）

ホットペッパーAPIはブラウザからの直接呼び出し（CORS）に対応していないため、端末・回線によっては検索が失敗することがあります。`proxy/Code.gs` を自分のGoogleアカウントで公開すると確実に動作し、APIキーも外部から見えなくなります。設置手順はそのファイルの冒頭コメントに書いてあります（無料・5分）。

発行された `https://script.google.com/macros/s/…/exec` のURLを、アプリのホーム画面下のバッジから設定してください（APIキーの代わりにURLを入れます）。

設定するとその場で接続テストが走り、どの経路で通ったか／どこで失敗したかが画面に表示されます。ホームの「接続テストを実行」からいつでも再確認できます。
